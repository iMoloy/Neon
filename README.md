## 📖 Overview

**Neon** is a cyberpunk-inspired static web page experiment with vivid neon colors, glowing effects, and dark backgrounds — built with pure HTML, CSS, and JavaScript.

> **Live at** → [https://imoloy.github.io/Neon](https://imoloy.github.io/Neon)

---

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| **HTML5** | Page structure |
| **CSS3** | Neon glow effects, animations, dark theme |
| **JavaScript** | Interactive UI behavior |

---

## ✨ Core Features

- **Neon Glow Effects** — CSS `text-shadow` and `box-shadow` for glowing UI elements
- **Dark Cyberpunk Theme** — Deep dark backgrounds with vivid accent colors
- **CSS Animations** — Pulsing and flicker effects
- **Responsive Layout** — Adapts across viewport sizes

---

## 📦 Dependencies

No npm packages required. Pure HTML, CSS, JavaScript project.

---

## 🚀 Run Locally

1. **Clone the repository**

   ```bash
   git clone https://github.com/iMoloy/Neon.git
   cd Neon
   ```

2. **Open in browser**

   ```bash
   open index.html
   ```
